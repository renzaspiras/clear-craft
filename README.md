# Clear Craft

Clear Craft bundles three skills for focused, evidence-based work:

- **Clear Progress** keeps replies concise and gives visible updates during multi-step work.
- **Evidence-Driven Engineering** researches meaningful uncertainty, implements the smallest supported change, and verifies results with evidence.
- **Interface Craft** helps build intentional, responsive interfaces and requires a Playwright visual review for rendered UI changes.

## Plugin contents

This repository is itself a skills-only Agent Plugin package. `plugin.json` describes the plugin, and each skill lives under `skills/<skill-name>/SKILL.md` with its optional Codex metadata beside it.

The plugin is also available privately in the creator's ChatGPT account. This repository contains its source package; cloning it does not grant account access to that private plugin.

## Use

Install or import the repository as an Agent Plugin in a compatible host. The skills are also readable as standalone skill folders by compatible agents that discover `skills/` directories.
